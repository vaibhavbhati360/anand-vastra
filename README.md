# Anand Vastra Bhandar

*Where Quality Meets Style*: website for Anand Vastra Bhandar, premium suits, kurtas, sherwanis and suiting & shirting.

**Live preview:** https://vaibhavbhati360.github.io/anand-vastra/

> Demo build. The phone number, address and hours are sample values. Model photos are illustrative stock images from [Pexels](https://www.pexels.com) (see `assets/stock-photos/CREDITS.md`); the kurta gallery shows the shop's own photos.

## Stack

Next.js 16 (static export) · React 19 · Tailwind CSS v4 · TypeScript

## Commands

| Command | What it does |
|---|---|
| `npm install` | Install dependencies |
| `npm run dev` | Local development at http://localhost:3000 |
| `npm run build` | Build the static site into `out/` |
| `npm start` | Serve `out/` locally |
| `npm run images` | Regenerate web images (needs the original photos in `assets/`, which are not in this repo) |
| `npm run deploy` | Build for GitHub Pages and publish to the `gh-pages` branch |
